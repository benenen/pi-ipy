# 交流与语言约定

> 交流用简体中文；**本仓库代码注释用英文**（用户 2026-10-02 明确要求）。

- 交流语言：默认使用简体中文；仅在用户明确要求时使用英文。
- **注释语言：代码注释一律英文**。`index.ts` / `lib/*.ts` 的注释是给读代码的人（和模型）看的，与文档的语种分开——文档、提交信息仍是简体中文。
  - 正例：`/** Session script directory; set for \`list\` so callers can build paths. */`
  - 反例：`/** 脚本目录，供 list 模式返回 */`
- 标识符（变量 / 类型 / 接口 / 函数名）保持英文，不翻译、不拼缩写之外的拼音。
- 面向用户的输出（回答、提交信息、文档）与既有仓库风格保持一致：简体中文。
